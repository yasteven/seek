# seek

A high-performance procedural macro engine that generates a transparent QUIC-based messaging layer, network frame chunking parsers, and asynchronous network loop streams mapped directly to your user-defined types.

## How it Works

The `seek!` macro parses a comma-separated list of types. At the crate root or module context where it is invoked, it outputs everything needed to run production-grade asynchronous engines:

* `ServerKernel` and `ClientKernel` execution loops.
* A `ConnectionHandle` struct tracking state per active socket connection.
* Dedicated, type-safe `tokio::sync::mpsc` channels automatically named after your identifier variants (e.g., `from_dude_snively` and `to_dude_snively`).

## Important: Ambient Dependencies

Because the code generated by `seek!` expands directly inside your application context, your dependent crate's `Cargo.toml` must include the networking, serialization, and runtime dependencies that the generated code calls:

```toml
[dependencies]
# Required by the generated macro runtime engines
quinn = "0.11"
rustls = { version = "0.23", features = ["ring"] }
rustls-pemfile = "2.1"
tokio = { version = "1.0", features = ["full"] }
futures = "0.3"
log = "0.4"

```

## Usage Example

### 1. Macro Declaration

Define your domain types, and let the macro generate your asynchronous kernels:

```rust
pub mod ksta 
{
  // Bring your tracking structs/enums into scope
  use super::{Snively, MadeBot, GotTtai, GotTick00, GotTick01};

  // This single invocation expands into the complete ClientKernel, ServerKernel,
  // and ConnectionHandle structs bound to these types.
  seek::seek! 
  {   
    Snively, 
    MadeBot, 
    GotTtai, 
    GotTick00, 
    GotTick01 
  }
}
```

### 2. Running the Generated Engine

Once the macro handles the heavy lifting, your code initializes endpoints and runs the loop. Here is an example setting up a QUIC backend server loop utilizing the generated infrastructure:

```rust
use std::sync::Arc;

async fn run_seek_server() -> Result<(), Box<dyn std::error::Error>> 
{
  // 1. Prepare standard transport configurations
  let certs = load_certs_from_pem()?;
  let key = load_private_key_from_pem()?;
  let mut server_config = quinn::ServerConfig::with_single_cert(certs, key)?;
  
  let mut transport_config = quinn::TransportConfig::default();
  transport_config.max_idle_timeout(None); // Keep connection alive indefinitely
  transport_config.keep_alive_interval(Some(tokio::time::Duration::from_secs(3600)));
  server_config.transport_config(Arc::new(transport_config));
  
  // 2. Bind the QUIC endpoint
  let endpoint = quinn::Endpoint::server(server_config, "0.0.0.0:4433".parse()?)?;
  
  // 3. Instantiate the macro-generated ServerKernel
  let (new_connection_sender, mut new_connection_receiver) = tokio::sync::mpsc::channel(256);
  let mut server_kernel = ksta::ServerKernel::new(endpoint, new_connection_sender);
  
  // 4. Spawn the runtime loop generated by the macro
  let (cancel_tx, cancel_rx) = tokio::sync::mpsc::channel::<()>(1);
  tokio::spawn
  ( async move 
    { if let Err(e) = server_kernel.run(cancel_rx).await 
      { log::error!("ServerKernel run loop encountered error: {:?}", e);
      }
    }
  );

  // 5. Handle connections and their type-safe MPSC channels
  while let Some(mut handle) = new_connection_receiver.recv().await 
  {
    log::info!("New connection handle created: ID {}", handle.c_id);
    
    // The macro automatically creates individual channels for each specified type!
    tokio::spawn
    ( async move 
      { loop 
        { tokio::select! 
          { // Type-safe stream generated by passing 'Snively' to the macro
            Some(snively_msg) = handle.from_dude_snively.recv() => 
            { log::info!("Received messages over QUIC chunk layer: {:?}", snively_msg);
            }
            // Type-safe stream generated by passing 'MadeBot' to the macro
            Some(bot_msg) = handle.from_dude_madebot.recv() => 
            { log::info!("Received data from bot: {:?}", bot_msg);
            }
          }
        }
      }
    );
  }
  Ok(())
}
```
